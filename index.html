Algorithm

Queens are placed row by row. A position is valid only when its column and both diagonals are free.

solve(row):
  if row == N: solution
  for col in columns:
    if safe(row,col):
      place queen
      solve(row+1)
      remove queen

Bitmask optimisation

Columns and diagonals are represented by bits, giving O(1) attack checks. The “Count All” button uses bitmasks.

For browser responsiveness, animation is limited to N ≤ 12 and the UI input to N ≤ 14. The included Python CLI can count N up to 20.
